# Model F-R1 Reconstruction Plan

## Known from repository source

- Model F design is implemented in the later source-level pipeline as `build_subgraph_extended_features()` in `src/abuse_ring_detector/features.py`.
- The ordered composition is 19 baseline + 18 graph + 30 temporal + 30 customer-relative + 20 two-hop + 20 subgraph = 137 features.
- The configured estimator is `HistGradientBoostingClassifier` with seed 42, `max_iter=160`, `learning_rate=0.08`, and `max_leaf_nodes=15`.
- The repository synthetic generator is deterministic for a fixed configuration and seed. Chronological split logic is provided by `split_by_time()`.
- The available calibration methodology fits Platt scaling and isotonic regression on validation scores and selects by validation Brier score.
- The requested operating threshold is 0.50.

## Reconstructed from available source

- A fresh corpus generated by `generate_ecosystem()` from the checked-in configuration/source.
- A chronological train/validation/test split from that generated corpus.
- The 137-column feature matrix and ordered feature list produced by the source pipeline.
- A new estimator fit only on the reconstructed training partition.
- A new calibration fit only on reconstructed validation scores.
